# Specs

Source-of-truth specifications for `control_admon_poncitlan`, organized by domain
(`{domain}/spec.md`). A domain file here is written by `sdd-archive`, which merges
a change's delta spec into it.

While a change is still open under `openspec/changes/<change>/`, its delta owns the
new requirements and this directory does NOT contain them yet. Read the delta to know
what a change adds; read the domain file to know what is already merged. Do not treat
a requirement that exists only in an open change as already merged.
